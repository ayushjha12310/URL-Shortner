# BitLinks 🔗 (Ya jo bhi aapke URL Shortener ka naam hai)

A simple, fast, and responsive URL shortener application built using Next.js and MongoDB.

##  Features
* **URL Shortening:** Convert long and complex URLs into short, clean links.
* **Redirection:** Automatically redirects shortened links to their original destination.
* **Database Integration:** Stores link mappings securely in MongoDB.
* **Responsive UI:** Clean interface built with Tailwind CSS.

##  Tech Stack
* **Framework:** Next.js (App Router)
* **Database:** MongoDB (Mongoose)
* **Styling:** Tailwind CSS

## Key Learnings
* Building full-stack web applications using Next.js App Router.
* Creating API routes and handling backend server logic in Next.js.
* Connecting Next.js to MongoDB for persistent data handling.
* Environment variable configuration and deployment workflow.
